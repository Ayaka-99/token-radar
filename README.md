A token launch radar that ranks unlaunched DeFi protocols by implied launch value, from a DefiLlama snapshot — with a web dashboard showing the board, protocol details, and farming steps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
